Welcome to NeverForgetSL

Welcome to the knowledge base! This guide will help you understand how to create and manage articles in this system.

Creating New Articles

To create a new article:

  1. Create a new HTML file in the articles directory
  2. Use the article template structure
  3. Add your content using HTML
  4. Update the main.js file to include your article in the articles array

Article Categories

Articles can be assigned to multiple categories. Categories help organize content and make it easier for readers to find related articles.

Best Practices

  • Use clear, descriptive titles
  • Add relevant categories
  • Include a brief introduction
  • Use headings to structure your content
  • Add links to related articles when relevant
